# Customer-Churn-Pred

## About the Project

This project uses machine learning to predict whether a telecom customer is likely to leave the company (churn). It explores customer data, preprocesses features, and compares different classification models.

## Objectives

- Analyze customer data using Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Train and compare machine learning models.
- Evaluate model performance using classification metrics.

## Technologies Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn, Plotly, Ydata Profiling
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- AdaBoost
- Gradient Boosting

## Project Workflow

1. Load the dataset and perform data cleaning.
2. Explore the data using visualizations.
3. Handle missing values and encode categorical features.
4. Split the data into training and testing sets.
5. Build preprocessing and model pipelines.
6. Compare models using cross-validation and evaluation metrics.
7. Tune hyperparameters using GridSearchCV.

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn plotly scikit-learn jupyter
   ```
3. Open the project in VS Code.
4. Open `main.ipynb`.
5. Select your Python environment and run the notebook cells in order.

## Dataset

The project uses the Telco Customer Churn dataset, containing customer information, services, billing details, and churn status.
